# DrawMeOne — Back to Basics (V2)

[Live website](https://drawmeone.com/) · [Artist Desk](https://drawmeone.com/studio-admin/index.php) · [Master TODO and pass log](docs/LAUNCH_TODO.md)

A personal gallery for genuine original drawings, fan art and simple commission enquiries. No customer account, quote, order or financial management platform. All work goes directly on main. Portfolio is live, commission intake stays closed during development.

V1 is preserved at [archive/v1-commission-platform](https://github.com/pixel375/drawmeone/tree/archive/v1-commission-platform). Existing credentials, private artwork, database, security and backup infrastructure are retained; historic data is not deleted. V1 routes are retired; old internal code remains for recovery and regression coverage while V2 is completed. Start each development session with the new canonical checklist. See the [short Artist Desk guide](docs/ARTIST_GUIDE.md) for everyday use.
