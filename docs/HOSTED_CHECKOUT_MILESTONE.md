# Hosted invoice links (provider-neutral preparation)

The artist can publish a manually created, fixed-amount single-use hosted invoice for an accepted, confirmed unpaid order, after checking the exact total, customer and receiving account. The site does not create provider invoices, collect card details, call provider APIs or verify payment automatically. Only an explicitly configured HTTPS host and fixed path prefix are accepted, with a restricted ASCII path and no query, credentials, fragment or alternate port. Compatibility with the chosen provider's actual invoice URL format must be confirmed before enabling; the current implementation intentionally excludes other URL formats.

The invoice URL is encrypted using AES-256-GCM and a derived application key, bound to the order ID, and a unique HMAC fingerprint prevents reuse. No raw URL is returned in detail APIs, audit events or exported customer data. The owner-only redirect checks eligibility again; links expire locally after seven days and are suspended permanently on first evidence recording. A replacement requires confirmation that the prior invoice is externally closed or settled and cannot accept another payment. Local suspension/expiry/revocation does not cancel a provider invoice, and cannot revoke a link the customer already copied. Actual provider single-use and exact amount are artist attestations, not independently verified by this website. Never rotate the existing application key without reviewing effects on encrypted invoice links, payment fingerprints and authentication. Keep approved provider host/prefix, account ownership, currency, refund and security setup under owner control. Separate activation and approval flags remain off.

Synthetic tests verify URL validation, owner-only access, expiry, encryption, replacement, evidence suspension and paid-order denial; browser tests exercise artist/customer controls. No live invoice, provider account or commercial switch was created or changed.
