# DrawMeOne v2.7 — Artist Desk launch readiness dashboard

Implemented November 23–24, 2026.

## Functionality

The authenticated Artist Desk Overview now presents a responsive **Launch readiness** list with a manual refresh button and summary count. The data is generated by the existing admin-session-protected `api/admin/overview.php` endpoint, **not** from browser guesses or manually maintained status labels.

Checks include:
- Configured transactional email transport
- Number of genuinely published portfolio drawings
- Owner-approved Terms/Privacy configuration and policy revision
- Verified customer-account registration availability
- Commission intake, private messaging and reference upload access gates
- Artist quote release plus customer acknowledgement gates
- Separate order confirmation gate
- Local encrypted backup freshness (under 36 hours)
- Explicit outstanding off-site recovery and payment-provider verification

A missing or disabled feature displays **Not enabled**, not a generic system failure. Future work displays **Planned**, not a misleading success state.

No credentials, private file names, recovery keys, customer identity, payment provider reference or raw environment values are sent to the browser. The entire readiness array is available only to an authenticated artist/admin session. Frontend labels use textContent, not HTML interpolation.

The dashboard is **informational only**: it contains no controls to enable customer registration, payments, policy approvals or public commission acceptance.

## Remaining launch blockers

The artist must approve legally accurate Terms and Privacy text, commercial copyright/licensing/refund rules and actual artwork before public business operations begin. Controlled real-account tests and independent off-site backup are also pending. Automated payment verification is not implemented.

## Operational integrity follow-up

The readiness dashboard now separately reports read-only database consistency checks for order/quote, verified payments, financial holds, delivery linkage and review allowances/approval binding. Daily SSH diagnostics scan private media for missing/unsafe files and invalid WebP headers, and verify delivery file sizes and SHA-256. The bounded scan reports incomplete coverage as a failure rather than implying full verification. No raw records or filenames enter CI logs. These checks detect inconsistencies, not automatically repair or change them. Independent off-site recovery, policy approvals and real-account onboarding remain launch blockers.

Browser coverage checks the expandable consistency panel across the existing mobile/desktop widths. The independent disposable restore now verifies the 005 review schema and table after import. A fresh local encrypted backup was requested following both additive schema migrations; its workflow result must be checked before claiming a new verified snapshot. All new commercial flags remain off.

First production integrity scan reported 10 portfolio variant permission failures. Existing artwork uploads create 0700 directories but used default file creation permissions. Updated the scanner to require both private storage directories to be owner-only and files not writable by other users; delivery files additionally require owner-only file permissions. New WebP writes explicitly chmod 0600. No existing files were modified; the follow-up live scan must confirm directory protection and image validity. This is not proof of actual file exposure.

## Controlled-stage reporting

The overview calculations are shared with the read-only CLI launch report. A separate configuration-only report shows preparation, onboarding, request/quote, payment, delivery and public-opening stages, each with pending configuration and required external evidence. It can be exported as JSON from Artist's Desk. External evidence cannot be inferred or marked complete automatically. Pricing readiness now includes valid public approved packages. The existing readiness indicators and integrity checks remain read-only. No launch authorization is granted by any report.
