# Customer artwork review and revisions

Optional pre-release proof workflow: artist selects a private staged draft, customer sees a dynamically generated watermarked WebP (maximum 720px longest edge), approves or requests one included revision with feedback. Exact accepted quote allowance is enforced transactionally. Proof access requires the paid-order evidence and owner session; original staged artwork remains private. After a proof has been offered, pending/rejected reviews block ready status and final release requires the latest approved draft, even if the review switch is later disabled. Pending/approved drafts are protected from removal; rejected drafts can be removed to free the four-draft staging limit while keeping the review record and feedback. A fresh draft is required for each review round. No extra fee, refund, dispute handling, post-release revisions or automatic email. Watermarks discourage copying but cannot prevent screenshots. The additive migration 005 is prepared, not applied until CI passes. Existing delivery without review remains allowed where no proof has been offered. Production switches remain off.
