# Artist intake control

An optional disabled-by-default DMO_INTAKE_CONTROL_ENABLED switch adds a conservative global cap of 1–100 active requests and an artist pause/resume toggle. When enabled without saved settings it starts paused (default cap 10). The settings are stored in the existing audit ledger; optimistic versioning and the same stable admin row lock serialize changes and customer submissions. Existing requests remain readable and actionable. A previously accepted idempotent retry is recognized even after an artist pause while the commercial gates remain open. The public status exposes availability/reason only, not queue counts or settings. The toggle cannot override the private environment's commercial or policy gates. Capacity counts all non-closed requests, including unpaid orders and held funds; it is not a time estimate or an automatic waiting list. No production flag changed. Synthetic HTTP tests cover new submission, at-capacity rejection, stale updates, pause, retry and history; browser tests exercise artist controls. Account security passed disposable integration and prior same-code browser/live runs.
