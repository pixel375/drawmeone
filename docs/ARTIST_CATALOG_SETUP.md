# Artist's Desk — catalog setup (pre-launch, not approval)

Follow the master [launch TODO](LAUNCH_TODO.md). All actual price, rights, delivery and capacity decisions are OWNER tasks CAT-04/05, LEG-03–06. No sample prices should be published.

1. In Packages, create an unpublished tier. Choose a unique lowercase slug; name and describe the actual drawing; list only included work, revision allowance and any agreed boundaries. Choose CAD or USD; use exact cents, with both estimates blank while undecided. Sort order controls display.
2. Create optional extras as unpublished records. Each has its own description, currency and estimate. Do not list optional extras as included features. Mixed currencies require an individual quote, never an added estimate.
3. After saving the tier, review extra availability: all current/future extras, or selected extras (including none). New extras are not automatically available in a restricted tier. Copying a tier does not copy visibility or compatibility. The preview reflects editor values, not approval.
4. Check the public preview text and exact prices; reload stale records before retrying. Save draft changes before publishing. Published edits are immediate once the publishing switch is authorized. Unpublish to remove an offer, not to erase order history. Keep a stable slug for existing public links.
5. The bounded inventory supports 100 saved packages and 100 saved extras; at most 50 packages and 100 extras published. These are technical guardrails matching public display capacity, not sales capacity. At the saved limit reuse existing drafts or request a reviewed archive/pagination enhancement. Do not delete history. Older oversized inventories are reported explicitly.
6. Actual intake capacity is separate from catalog limits. Keep paused until the controlled launch runbook authorizes testing. Verify closed, paused, at capacity, and open states before allowing public requests. A request is not an order; an accepted quote is not proof of payment.
