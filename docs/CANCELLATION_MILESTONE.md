# Commission withdrawal and unpaid cancellation

Prior consolidated journey passed disposable HTTP integration and all relevant source/browser/live checks. Separate cancellation switches default off. Customers can withdraw before accepting a quote; outstanding offers are superseded atomically while original records remain. No order or accepted quote can be withdrawn. Artist can record a cancellation only of a confirmed unpaid pre-production order with no non-rejected payment evidence, financial exception, unclosed invoice, draft, proof or deliverable. Requires explicit confirmation of no external funds and communication under approved terms. Locks serialize against quote acceptance, invoice issuance and payment reconciliation. Quote remains accepted as historical evidence, request and order become cancelled, freeing capacity. No money moves, no refund is sent, and no data is deleted. Paid cancellations and partial refunds are outside scope. External payment state is an artist attestation, not an automated verification. Tests cover ownership, CSRF, accepted quote denial, invoice closure, history and UI. No production settings changed.
