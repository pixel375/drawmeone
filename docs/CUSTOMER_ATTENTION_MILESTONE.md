# Customer commission updates

The first history response includes recent available quote, proof, invoice and finished-artwork shortcuts across the signed-in customer's own history, independent of the first page of request cards. Each shortcut opens the normal private request detail; it does not approve, pay or download anything automatically. Quotes require a current actionable offer and eligible policy; proofs and deliveries reuse the owner-access queries; invoices reuse the existing customer checkout eligibility check. At most ten references per category are returned, with bounded candidate scanning. This is not an exhaustive unread or task count, and current detail endpoints remain authoritative. No sensitive URLs, private file paths, payment evidence or internal IDs appear in the summary. New requests may remain paused while existing customers use their history. No business gate was changed. Added isolated real HTTP and browser QA.
