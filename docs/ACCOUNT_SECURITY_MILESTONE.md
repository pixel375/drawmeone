# Customer account security milestone

Corrected operational integrity scan and encrypted local backup passed production verification. Added verified-customer-only password changes and other-session revocation, protected by current password, CSRF, origin checks, throttling and account/session locks. Password changes invalidate all sessions and outstanding recovery tokens. Login rechecks credentials under the account lock before creating a session and issues its cookie after commit. The account page clears private content on departure and reloads when restored from browser history; confirmed sign-out and password changes return to fresh sign-in with CAPTCHA initialized. Device counts are active sessions, not unique physical devices. No production customer account is created or commercial flag changed. Disposable HTTP and browser tests cover security controls; actual live customer sign-in remains gated. Pending CI and live verification.
