# Artwork concurrent editing and upload protection

New dashboard requests include the original saved sort order or alt text. Server compares it against the locked database row and rejects a conflict with HTTP 409. The dashboard retains unsaved input, locks editing and requests a refresh. Legacy requests without the optional expected field remain compatible during asset rollout. Database-scoped advisory upload lock serializes the 2,000-row capacity check and insert across web requests; a competing request times out after three seconds with HTTP 409. The lock is tied to the nonpersistent database connection and released at request end. Private previews now send explicit no-store and noindex even on denied access. Disposable HTTP tests cover lock contention, correct/stale expectations and the private preview header. No schema migration or activation change.
