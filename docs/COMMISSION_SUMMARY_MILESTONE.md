# Private printable commission summary

Customer-authenticated, owner-scoped server-rendered snapshot of the request, latest delivered or accepted quote, itemized terms, historical policy receipt link, confirmed order and current recorded payment status. No JavaScript required to print using the browser's print menu. If the accepted quote and order cannot be matched unambiguously, no financial summary is asserted. Never exposes draft quotes, private brief/messages/images, download/checkout links, transaction references or credentials. No-store, noindex/nofollow, strict CSP. It is not a tax invoice, bank receipt or provider confirmation. Synthetic HTTP tests cover ownership, unpaid/reconciled states and secret exclusion. No production data or switches changed.
