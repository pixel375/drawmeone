# Commission composer editing safeguards

The artist sees an explicit warning while an unsaved note, customer reply or quote is present. Switching to another request, closing the detail or changing customer scope requires confirmation before clearing these fields. Cancelling preserves the current request and input. Copying a saved quote over unsaved work also requires confirmation. Confirmed quote creation clears the composer only, reducing accidental duplicate versions; unrelated notes and messages remain. Quote line controls respect draft eligibility, busy state and the twelve-line limit. Nothing is saved in localStorage, no customer message is sent by these safeguards, and forced sign-in resets still clear private content. Synthetic browser tests cover cancelled and confirmed navigation and successful quote creation. No commercial gate changes.
