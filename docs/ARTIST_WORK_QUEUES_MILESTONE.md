# Artist action queues

The dashboard and request filters share fixed SQL predicates for replies needed, accepted quotes awaiting an order, overdue and upcoming deadlines, latest revision requests and pending proof reviews. Reply-needed means the last non-internal conversation message is from a customer on an open request; it is not an unread/read receipt or a delivery guarantee. Internal notes do not clear that queue. The Messages tab includes a one-message-per-conversation reply-needed view. Upcoming includes today through UTC date +7, overdue is strictly earlier. Proof and revision queues reflect latest recorded review state, not a permission to change financial or delivery state; action endpoints retain all gates. Counters can overlap and are not a total number of unique requests. No records or flags changed and no migration required. HTTP tests exercise message, proof and revision queue transitions; browser tests exercise inbox filtering.
