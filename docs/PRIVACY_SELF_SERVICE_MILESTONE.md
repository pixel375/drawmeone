# Privacy self-service milestone

Historical-policy continuation passed all five test suites. Customer records export and manual privacy request intake use a separate disabled-by-default switch, verified customer session, CSRF, password confirmation and rate limits. Export contains structured customer-visible commission records, messages, released quotes, order/payment metadata, proof decisions, image metadata and recorded policy/privacy receipts. It deliberately excludes image bytes, internal notes, raw transaction references, authentication secrets and storage paths; it is not a complete legal access response. It fails explicitly above 10,000 rows or 8 MiB of row JSON rather than silently truncating. No server-side export file or email attachment is created. The customer can submit one open access/correction/deletion request and withdraw it; the artist can record review and a customer-visible outcome through the paginated open queue. Audit entries preserve the history; no account, payment, artwork or record is altered/deleted by this workflow. The artist must handle identity verification for other channels and actual responses separately. Owner-approved retention rules, independent recovery, manual response procedures and legal review remain required. No commercial switch changed. Tests use synthetic isolated records only.
