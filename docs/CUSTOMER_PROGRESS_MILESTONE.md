# Customer progress and actionable history (Session XVII)

The authenticated commission workspace summarizes recorded milestones, not percentage completion or a promised delivery date. Payment is verified by the artist, never inferred from a hosted invoice.

- Review shortcuts distinguish available, unavailable and historical quotes/proofs.
- Proof controls require server-reported eligibility and a successfully loaded watermarked image. Payment holds/refunds and cancelled orders suppress stale artwork actions. The protected media and decision endpoints remain authoritative.
- The customer attention list excludes proofs with an ineligible policy record; the server returns only customer-owned references.
- Whole-history search supports the labels shown to customers, along with raw status/category aliases; it never searches briefs or private messages.
- Browser state-matrix and disposable HTTP regression contracts cover the changes. Actual CI and Hostinger results must be checked by commit.

No feature approval, payment provider, commercial settings, public opening, database migration or production customer records are changed. Controlled authenticated real-device QA remains required.
