# Draw Me One — quick artist guide

Open the [Artist Desk](https://drawmeone.com/studio-admin/index.php) and sign in using your existing administrator account. Never share that password.

## Artwork
1. Select one or more JPG, PNG or WebP drawings (up to 8 MB each, within image dimension limits) and upload.
2. Uploads start private. Preview them, then select the ones you want visitors to see and choose Publish selected.
3. Use Make private if a drawing should no longer appear. Under More options you can add a short image description for accessibility or adjust the published order. No description is required.
4. Check the [live gallery](https://drawmeone.com/) on a phone and computer. The full image viewer should show the entire drawing.

## Requests
Keep Accepting commissions off until you are ready and the owner has approved opening. When on, visitors send their name, email and drawing idea without registering. Open the inbox, mark requests read, reply using your own email application, and archive handled requests. Archiving is not deletion. If a notification fails, the saved request may still be available in the inbox. Check the inbox directly.

Ask for any necessary reference images by email after the initial request. Don't ask visitors to send passwords, card numbers or unnecessary sensitive details. There is no attachment upload, quote system, checkout or payment tracking on this site.

## Payments
Enter only public method names and, optionally, a starting price. Agree on the final price and send payment instructions privately. Leave the fields blank if you have not decided. Do not enter account credentials or card details.

## My website
Edit the headline, short introduction, optional Instagram/TikTok profile links and the default light or dark appearance. Visitors can switch themes themselves. Save changes and check the public page.

## Before opening commissions
Review the live layout, artwork rights, real contact and payment details, privacy/retention decisions, offsite backup and recovery, and a controlled delivery test. The owner must explicitly approve opening. The site is a personal gallery, not a professional order-management system.

If something fails, avoid submitting the same action repeatedly; refresh and verify what was saved. For technical recovery, use the project's existing backup/restore procedures and contact the site administrator.
